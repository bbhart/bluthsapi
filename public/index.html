Quotes API

Every quote is a line and (mostly) whoever said it. Ask for one at random, ask for a particular character, or ask for one with a picture attached. No API key, no sign-up, no account, just be nice and don't abuse.

Endpoints

GET /api/quotes/random

Random quote

One quote from anyone in the show. A different one each time.

200 OK 
{
  "data": {
    "id": "quote-001",
    "quote": "There are dozens of us! DOZENS!!!",
    "speakers": "Tobias"
  }
}
GET /api/quotes/{character}

Quote by character

One quote from the character you name. Case does not matter, so gob, Gob and GOB all work.

Quotes that are exchanges match on any of their speakers, so /api/quotes/michael can return a quote whose speakers are "Lucille,Michael".

200 OK · /api/quotes/michael 
{
  "data": {
    "id": "quote-288",
    "quote": "Lucille: You tricked me. Michael: I deceived you, Mom.",
    "speakers": "Lucille,Michael"
  }
}

If not found A character with no quotes on file returns 404 and an error message naming the character you asked for.

GET /api/quotes/meme

Quote with an image

One quote that has a picture attached, as imageUrl. Good for posting.

200 OK 
{
  "data": {
    "id": "quote-042",
    "quote": "There's always money in the banana stand.",
    "speakers": "George Sr.",
    "imageUrl": "https://bucket.s3.amazonaws.com/banana-stand.jpg"
  }
}

The record

Every response wraps one quote in data.

FieldWhat it holds
id Identifier for the quote, such as quote-288.
quote The line itself. Exchanges keep their speaker prefixes.
speakers Everyone who speaks, comma separated, in the order they speak — "Lucille,Michael". Empty when nobody has identified the speaker yet.
context Episode or situation, when it is known.
imageUrl Full address of the picture. Only on quotes that have one.

When something goes wrong

Errors come back in the same shape every time: one error field saying what happened.

404 Not Found 
{
  "error": "No quotes found for character: Hermano"
}
