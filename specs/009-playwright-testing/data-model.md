# Data Model: Playwright E2E Testing Framework

## Test Entities

### Test Suite
A collection of related test cases organized by feature area.

| Field | Type | Description |
|-------|------|-------------|
| name | string | Suite name (e.g., "prettyquote", "api", "index") |
| test_cases | TestCase[] | Collection of test functions |
| fixtures | Fixture[] | Shared setup/teardown logic |

**Locations:**
- `tests/e2e/test_prettyquote.py` - PrettyQuote page tests
- `tests/e2e/test_index.py` - Index page tests
- `tests/api/test_endpoints.py` - API endpoint tests

### Test Case
An individual test verifying a specific behavior.

| Field | Type | Description |
|-------|------|-------------|
| name | string | Test function name (test_*) |
| description | string | Docstring explaining what's tested |
| setup | Fixture[] | Fixtures required for this test |
| assertions | Assertion[] | Expected outcomes |

**Naming convention:** `test_<feature>_<behavior>` (e.g., `test_copy_quote_updates_clipboard`)

### Page Object
Abstraction for interacting with application pages.

| Field | Type | Description |
|-------|------|-------------|
| base_url | string | Server URL (http://localhost:8000) |
| selectors | dict | CSS/ID selectors for page elements |
| actions | method[] | User interaction methods |

**Page Objects:**

#### PrettyQuotePage
| Selector | Target | Purpose |
|----------|--------|---------|
| `#quote` | p.quote-text | Quote text element |
| `#copy-btn` | button | Copy Quote button |
| `#reload-btn` | button | Reload button |
| `#quote-image` | img | Quote image (when present) |
| `#image-container` | div | Image container |
| `#toast` | div | Toast notification |

| Method | Description |
|--------|-------------|
| `goto()` | Navigate to /prettyquote.html |
| `get_quote_text()` | Return quote text content |
| `click_copy_quote()` | Click copy button |
| `click_reload()` | Click reload button |
| `click_image()` | Click image to copy |
| `is_image_visible()` | Check if image displayed |
| `get_toast_text()` | Get toast notification text |

#### IndexPage
| Selector | Target | Purpose |
|----------|--------|---------|
| `h1` | heading | Page title |
| `.endpoint` | div | Endpoint documentation blocks |
| `script[src*="gtag"]` | script | Google Analytics script |

| Method | Description |
|--------|-------------|
| `goto()` | Navigate to / |
| `get_title()` | Return page heading |
| `has_analytics()` | Check for GA script |

### Test Report
Output showing test results.

| Field | Type | Description |
|-------|------|-------------|
| passed | int | Count of passing tests |
| failed | int | Count of failing tests |
| duration | float | Total execution time (seconds) |
| failures | FailureDetail[] | Details of failed tests |

**Generated by:** pytest standard output and optional HTML report

```json

  "detail": "string"
}
```

## State Transitions

### Page Load States
```
Initial → Loading → Loaded (quote displayed)
                  → Error (API failed)
```

### Copy Operation States
```
Ready → Copying → Success (toast: "Copied!")
                → Failed (toast: error message)
```

### Reload Operation States
```
Ready → Loading (button.loading class) → New quote displayed
```

## Relationships

```
conftest.py
    └── Fixtures
        ├── start_server (session scope)
        ├── browser_context_args (clipboard permissions)
        └── base_url

pages/
    ├── base_page.py → BasePage (shared methods)
    ├── pretty_quote_page.py → PrettyQuotePage extends BasePage
    └── index_page.py → IndexPage extends BasePage

tests/
    ├── e2e/
    │   ├── test_prettyquote.py → uses PrettyQuotePage
    │   └── test_index.py → uses IndexPage
    └── api/
        └── test_endpoints.py → uses httpx directly
```
